# Security Policy

## Supported versions

Only the latest release of jebaited_player receives security fixes. Please update to the latest version (the player updates itself, or download it from [Releases](https://github.com/jebaitedcro7/jebaited_player/releases)) before reporting.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately on GitHub: **Security → Report a vulnerability** on this repository. Please include:

- the player version (Settings → About),
- steps to reproduce,
- what an attacker could do with it.

Reports are answered as soon as possible. Fixes are published as a new release and listed in the changelog.

## Scope

The player, its installer and the update packages published in this repository's Releases. Problems in third-party components (mpv/libmpv, FFmpeg and others listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)) should also be reported to their projects.
